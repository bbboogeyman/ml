# 🏠 House Price Prediction - Machine Learning Project

## 📋 Краткое описание
Прогнозирование цен на жилую недвижимость с использованием различных алгоритмов машинного обучения. Проект демонстрирует полный пайплайн обработки данных и сравнение моделей.

## 🎯 Цель проекта
Разработать модель для точного предсказания цен на дома на основе 79 характеристик недвижимости.

## 📊 Данные
- **Источник:** Kaggle - House Prices Competition
- **Обучающая выборка:** 1460 объектов, 80 признаков
- **Целевая переменная:** SalePrice

## 🛠️ Методология

### 1. Обработка данных

#### Заполнение пропущенных значений
| Тип признаков | Стратегия заполнения | Примеры |
|---------------|----------------------|---------|
| **Категориальные (отсутствие объекта)** | Замена на 'None' | PoolQC, MiscFeature, Alley, Fence |
| **Числовые (LotFrontage)** | Медиана по районам | LotFrontage → median по Neighborhood |
| **Год постройки гаража** | Год постройки дома | GarageYrBlt → YearBuilt |
| **Остальные числовые** | 0 или медиана | MasVnrArea → 0 |

#### Feature Engineering
- **HasGarage:** Бинарный признак наличия гаража
- **GarageAge:** Возраст гаража (YrSold - GarageYrBlt)
- **TotalBathrooms:** Общее количество ванных комнат
- **Логарифмирование цены:** log1p(SalePrice) для нормализации

#### Кодирование признаков
- **Порядковое кодирование:** Качественные оценки (Ex:5, Gd:4, TA:3, Fa:2, Po:1, None:0)
- **One-Hot Encoding** 
- **Target Encoding** 

### 2. Анализ данных
- **Распределение цен**
- **Корреляционный анализ:** Выявлены наиболее влиятельные признаки
- **Визуализация:** Гистограммы, scatter plots, heatmaps

### 3. Построение моделей
Тестирование 13 различных алгоритмов:
- Линейные модели (Linear, Ridge, Lasso, ElasticNet)
- Байесовские методы (Bayesian Ridge)
- Методы на основе соседей (KNN, SVR)
- Древовидные модели (Decision Tree, Random Forest)
- Ансамблевые методы (AdaBoost, Gradient Boosting, XGBoost, LightGBM, CatBoost)

### 4. Валидация
- **Разделение:** 80% train / 20% test
- **Кросс-валидация:** 5-fold
- **Подбор гиперпараметров:** RandomizedSearchCV для Random Forest
